# РадиоКлад — каталог скупки радиодеталей

Репозиторий `Lomonimus02/dragsoyuz2` содержит исходники РадиоКлада
(`https://radio-klad.ru`), созданного на основе RadioDetali / Драгсоюза.
Синхронизация от 23 октября 2026 года включает оформление РадиоКлада, обработку
фотографий и водяные знаки, SEO, редактирование описаний, WhatsApp и ручные
позиции в описи администратора с изменением количества.

## Сборка РадиоКлада

Используется Node.js 22. Перед сборкой задайте переменные окружения:

```dotenv
NEXT_PUBLIC_BASE_URL=https://radio-klad.ru
NEXT_PUBLIC_SITE_BRAND=РадиоКлад
NEXT_PUBLIC_SITE_THEME=radioklad
LOCAL_PREVIEW=0
NEXT_PUBLIC_JIVO_WIDGET_ID=aXuLlAFWY4
# Счётчик 113820841 вшит в тему radioklad. Эта переменная его не подменяет
# и нужна только чужому магазину; на РадиоКладе оставьте пустой.
NEXT_PUBLIC_YANDEX_METRIKA_ID=
```

Для работы приложения также нужны `DATABASE_URL`, `ADMIN_PASSWORD` и отдельный
случайный `ADMIN_SESSION_SECRET`. Их значения хранятся вне Git. Настройки
контактов, товаров и цен находятся в базе данных; новые загруженные фотографии
также не добавляются в репозиторий.

```bash
npm ci
npx prisma generate
npx next build --webpack
```

Перед запуском обновлённого приложения применяются миграции из
`prisma/migrations`. Ручные позиции администратора сохраняются в браузере,
а WhatsApp отображается только после заполнения номера в админке.

На 23 октября 2026 года production обновляется загрузкой проверенной standalone
сборки на сервер. Сохранённый `.github/workflows/deploy.yml` — унаследованная
настройка сборки Драгсоюза для ветки `master`; отправка в `main` не запускает
её и не обновляет production. Настройки Docker ниже также относятся к
исходному проекту и требуют адаптации перед использованием для РадиоКлада.

## Документация исходного проекта RadioDetali

Сайт-каталог для скупки радиодеталей и лома драгметаллов с динамическим расчётом цен на основе биржевых курсов металлов.

## 🏗️ Технологии

- **Framework:** Next.js 14+ (App Router)
- **Database:** PostgreSQL (Docker)
- **ORM:** Prisma
- **UI:** Tailwind CSS, Lucide Icons
- **Язык:** TypeScript

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск PostgreSQL через Docker

```bash
docker-compose up -d
```

Это запустит контейнер PostgreSQL на порту 5432.

### 3. Настройка переменных окружения

Файл `.env` уже создан с настройками по умолчанию. При необходимости отредактируйте:

```env
DATABASE_URL="postgresql://radiodetali:radiodetali_secret@localhost:5432/radiodetali?schema=public"
```

### 4. Применение миграций и генерация Prisma Client

```bash
npm run db:migrate
```

Или для быстрого прототипирования (без создания файлов миграций):

```bash
npm run db:push
npm run db:generate
```

### 5. Заполнение базы тестовыми данными

```bash
npm run db:seed
```

### 6. Запуск приложения

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

## 📊 Просмотр базы данных

## 💰 Бизнес-логика

### Расчёт цены товара

Цена товара рассчитывается по формуле:

```
Цена = (Содержание_Au × Курс_Au) + (Содержание_Ag × Курс_Ag) + 
       (Содержание_Pt × Курс_Pt) + (Содержание_Pd × Курс_Pd)
```

Где:
- **Au** - Золото
- **Ag** - Серебро  
- **Pt** - Платина
- **Pd** - Палладий

### Фиксированная цена

Для отдельных товаров можно установить фиксированную цену (`isFixedPrice: true`), 
которая будет использоваться вместо расчётной формулы.

## 🗃️ Модели данных

### MetalRate
Хранит текущие закупочные курсы металлов (одна активная запись).

### Category
Древовидная структура категорий с поддержкой вложенности.

### Product
Товар с содержанием металлов и опциональной фиксированной ценой.
